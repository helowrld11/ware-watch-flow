It brings the important parts of warehouse operations into one place — products, stock levels, recent movements, low-stock items, suppliers, customers, and order status — so you do not have to jump between different screens just to understand what is happening in the system.

The current version is set up with seeded mock data and an in-memory database service, which makes it easy to run, test, and extend without needing a full backend right away. The product page supports search and quick actions, while the dashboard gives a clean snapshot of inventory health, incoming and outgoing movement, and items that need attention. It is a practical starting point for a real warehouse workflow, and a solid base for adding persistence, role-based access, and more advanced reporting later.
